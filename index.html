Lease Mileage Calculator

Optional: Use URL Parameters for Autofill/Auto-Run

How it works: Append query parameters to the URL (e.g., after lease-calc.html) to pre-fill fields. If all three are provided, it auto-calculates on load.

  • Parameters:
    • startDate: YYYY-MM-DD (e.g., 2025-01-01)
    • termMonths: Number of months (e.g., 36)
    • annualMiles: Annual allowance (e.g., 12000)
  • Partial vs. Full: Use any subset to autofill—manual calc still needed unless all are set.

Examples:

Autofill only term: ?termMonths=36

Full autofill + auto-run: ?startDate=2025-01-01&termMonths=36&annualMiles=12000

Copy the full URL from your browser's address bar to share pre-filled links. Uses today's date (Dec 05, 2025) for calcs.
